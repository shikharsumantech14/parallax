# EXPLAIN.how — the Phase 6.1 copy review

> **Why this exists.** `core/VizCard.astro` renders only an *authored* `howToRead`. It deliberately does not fall back to `EXPLAIN[kind].how`, because those strings were written as interaction cues for the ⤢ modal ("Drag to spin the globe…"), not as in-flow reading guidance above a graphic. Flipping the fallback on (REVAMP-PLAN §4 Phase 6.1) changes every viz section that lacks an authored `howToRead`. This table is the review that flip is gated on. **Generated by the agent, ruled on by the operator.**
>
> **Verdict column — fill in one of:** `ok` (reads fine in-flow as-is) · `rewrite` (needs an in-flow version; the agent drafts it) · `never` (must not auto-render; stays modal-only). Blank = not yet ruled.

## How to read the Live column
