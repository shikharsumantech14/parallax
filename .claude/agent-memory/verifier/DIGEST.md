# Verifier memory digest
Digest of the memory as of 2026-09-28. Read-only during a run. Updates happen in a post-review pass.

## Where drafts go wrong
- Numerals copy right, their scope does not. Check each qualifier in the dossier's full sentence (mean, estimated, about, in one region) wherever the figure appears.
- A bound flips ("at least X" becomes "only to X"), always toward the argument. A figure tied to one condition gets stated of both ("either", "both", "same").
- A superlative needs a ranking, not a value. Evidence from one period supports none across periods.
- Recompute every quotient, share and fraction word from the draft's operands, even if the dossier or a panel calls it checked. Test any count or order a title or intro claims against its graphic's data.
- Verbatim words and attribution are separate checks. Where a claim traces to a quoted passage, mark the words the draft added.

## Checks that pay
- Note the one source id carrying each distinctive figure and confirm it is in the refs of every section using it. An event source cannot carry a yearly total.
- Compare each source line's outlets and date with its section's refs and events.
- Repeated figures must agree, and each field with its own section's caption and data.
- Story beats must index the right section, keep its hedges and repeat any caption-only caveat.
- An annotation anchor matching no point exactly renders nothing. Refs never render, so a section with no source line shows none.
- Each EDITOR note is a claim. Trace the document it names.
- Spot-check long carried-over series at the dossier's anchors. Distrust one whose credited provider is missing from sources[].

## Sources and quotes
- Tier decides the anchor, ingest decides quoting. An open live source the dossier fetched is quotable.
- Judge tiers as a set. Many T4 outlets can be diverse yet unanchored, one T7 author is neither. Name one thinly sourced key figure and its primary. Count diversity without unreferenced ids.
- When a ruling moves a quote to the reporting outlet, the primary it set aside must not be in that section's refs.
- A dossier's off-allowlist note is dated. Its recheck is a dossier fix.

## Severity
- Open the verdict with what was resolved, then each blocker's kind and cost. Only an invented fact or a non-quotable quote needs another agent run. When no blocker is an accuracy error, say so first.
- ❌ for a self-refuting sum or a superlative the dossier refutes, each a one-clause fix. List the dossier fix separately. ⚠️ for missing refs, a flipped bound, a branch error, an added entailment.
- A departure forced by a later ruling or research pass, the storyboard's own constraints or a field's value range is right. Require a note naming it.
- Not defects: status published on an in-place rewrite (✅, waiver named), Hindi in a jargon-buster hindi slot, a "not X" clause narrowing a figure.
- Head fields sit at their caps, so most fixes must swap words. Name the cap each fix spends.
