# Candidate file format

The discovery agent writes one of these per category per run. Format:

```markdown
# <Category> — Candidate issues for week of YYYY-MM-DD

Generated by /pipeline-discover on YYYY-MM-DD HH:MM IST.
Sourced from <N> sources in research/_sources/<category>.md.

## How to pick
Mark exactly one candidate by changing its line `status: open` to
`status: chosen`. The pipeline reads the chosen one in the next step.

---

## C-01 · <one-line hook>

- **status:** open
- **why now:** <1-2 sentences on why this is timely / structurally interesting>
- **angle:** <the Parallax angle — what perspective shift, what structure to reveal>
- **suggested kinds:** <which existing section components fit, e.g. timeline, comparison, prose, paradox>
- **est. read time:** <X min>
- **sources (3-5):**
  - https://...
  - https://...
  - https://...
- **notes:** <any flags — paywalled sources, sparse data, contested facts, recent breaking>

---

## C-02 · <one-line hook>

- **status:** open
- ...

(continue for 5-10 candidates)
```

## Rules the agent follows

- Each candidate is **one** issue (not a topic + multiple angles)
- Hook is the headline-style framing, not the sourced topic — Parallax voice
- "Why now" must be tied to a concrete recent event/data release/anniversary
- Suggested section kinds are picked **only from the existing registered set**
  in `src/content/config.ts` (no inventing new component types at this stage)
- Sources are **only from** the per-category allowlist in
  `research/_sources/<category>.md`
- 5-10 candidates per run; better to surface fewer high-signal ones than 10 weak ones
- No invented facts — if the agent doesn't have evidence for a candidate, it's omitted

## Example (filled)

```markdown
## C-01 · The 138 ASAT tests that nobody counted

- **status:** open
- **why now:** ESA Space Environment Report 2025 (April 2025) tallied
  the cumulative debris from anti-satellite tests for the first time.
- **angle:** Parallax shows the asymmetry — three nations conducted
  4 ASAT tests; the resulting debris cloud touches every other operator
  for decades. Compare to nuclear test bans.
- **suggested kinds:** timeline, comparison, data-readout, paradox
- **est. read time:** 6 min
- **sources:**
  - https://www.esa.int/.../space-environment-report-2025
  - https://swfound.org/.../asat-debris-tracking
  - https://leolabs.space/news/...
- **notes:** ESA report is a ~50pg PDF — researcher will need to
  WebFetch + extract the relevant tables.
```
