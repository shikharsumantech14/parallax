# Travel — source allowlist

Tiered, viewpoint-tagged allowlist for the **travel** topic — places, crossings,
rituals, infrastructure, the political economy of moving people. Format + tiers +
vetting rubric: see `_TAXONOMY.md`. Bias toward sourced narrative + primary data;
reject sponsored content / influencer roundups / SEO travel-tax churn farms.

**Viewpoint clusters (travel)** — only T3/T4/T7 carry one; T0/T1/T2 are `n/a`:
- `industry-official` — UN Tourism / ICAO / IATA / operators / national boards (the sector's own framing)
- `independent-critical` — overtourism, tourism labour, aviation climate, displacement
- `place-local` — regional / Indigenous / destination-community perspective
- `primary` — data/statistics/official documents (used as a cluster tag only where an interpretation source is primarily a data shop)

Diversity gate (per `_TAXONOMY.md` §5): every issue needs ≥3 sources across ≥2
clusters on the interpretation layer **and** ≥1 T0/T1/T2 anchor for load-bearing
facts. Tourism-volume / aviation-safety / emissions figures are settled empirical
questions → anchored in T0–T2, **not** "balanced" against opinion.
