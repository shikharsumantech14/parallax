# Politics — source allowlist

Trusted sources the discovery agent mines for candidate political issues.
Indian politics first; comparative international second. Edit freely.

## Primary sources

- **The Hindu — Politics** — https://www.thehindu.com/news/national/politics/ — type: newspaper — focus: parliamentary politics, electoral analysis
- **Indian Express — Political Pulse** — https://indianexpress.com/section/political-pulse/ — type: newspaper — focus: governance, party politics
- **The Wire — Politics** — https://thewire.in/politics — type: digital — focus: investigative, structural reporting
- **Caravan Magazine** — https://caravanmagazine.in/politics — type: longform — focus: deep political reporting
- **Scroll.in — Politics** — https://scroll.in/category/politics — type: digital — focus: news + analysis
- **Economic & Political Weekly** — https://www.epw.in/ — type: academic — focus: structural / theoretical
- **The Print — Politics** — https://theprint.in/category/politics/ — type: digital — focus: news + opinion

## Primary data sources (cite directly)

- **PRS India** — https://prsindia.org/ — type: think-tank — focus: bills, parliamentary data, MP voting
- **Lok Sabha (Sansad)** — https://sansad.in/ls — type: official — focus: vote records, debates, committee reports
- **Election Commission of India** — https://www.eci.gov.in/ — type: official — focus: election results, voter data
- **Ministry of Statistics (MoSPI)** — https://www.mospi.gov.in/ — type: official — focus: census, NSS data

## Secondary / international comparison

- **The Economist — Asia** — https://www.economist.com/asia — type: magazine — focus: India in regional/global context
- **Foreign Policy — South Asia** — https://foreignpolicy.com/region/south-asia/ — type: magazine — focus: geopolitics
