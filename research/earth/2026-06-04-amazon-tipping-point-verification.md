## Required fixes before publish

1. **Timeline label "Clearing falls to a 12-year low" (Jul 2025 row) is off
   by one.** "Lowest annual tally since 2014" spans 11 years (2014→2025), and
   the dossier says exactly "lowest since 2014." The note on the same row is
   correct; only the bold label rounds to "12-year." Change the label to
   "**Clearing falls to an 11-year low.**" or, safer, "**Clearing falls to its
   lowest since 2014.**" (the data-readout tile already uses the latter
   phrasing — match it). This is the single blocker keeping the verdict at
   NEEDS REVISION rather than APPROVED.

## Optional improvements

1. **Consider adding explicit `sourceRefs[]` to each section.** All sourcing
   is currently carried inline (in `data.source`, quote attributions, and tile
   notes), which is valid and builds — the delimitation benchmark does the
   same for several sections. But wiring `sourceRefs: [src-01, src-02]` on the
   threshold sections would let any future Sources component cross-link the
   claims. Not a blocker.

2. **"~1.3°C and rising" (comparison · "Where the dial sits today").** The
   dossier anchors current warming via the WMO/Carbon Brief framing ("around
   2030", 91% chance of a ≥1.5°C year) rather than a specific present value.
   "~1.3°C" is consistent with widely reported current warming but is not a
   line in the dossier. Either soften to a sourced framing ("approaching
   1.5°C") or leave it as common-knowledge context — low risk either way, but
   it is the one number in the issue not directly traceable to a dossier entry.

3. **Nobre quote is fragmented across two quoted spans** ("by 2040," … "it is
   impossible to save the Amazon"). Both fragments are verbatim sub-strings of
   the dossier §5 quote, and the construction reads cleanly. No change needed;
   noting only that the full dossier quote is "If we don't do that by 2040, we
   cross the tipping point; then it is impossible to save the Amazon" — if the
   editor prefers, the unfragmented line could be used as a single pull.
